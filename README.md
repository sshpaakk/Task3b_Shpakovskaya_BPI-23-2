
# Лабораторная работа
## Справочник пользователей с использованием REST API

### Цель работы
Создать веб-приложение для загрузки пользователей и их публикаций через REST API с использованием HTML, CSS и JavaScript.

### Запуск приложения
1. Открыть папку проекта в VS Code.
2. Запустить index.html через Live Server или открыть файл в браузере.
3. Нажать кнопку «Загрузить пользователей».
4. Использовать поиск по имени.
5. Нажать «Показать публикации» у выбранного пользователя.

### Результаты проверок
1. Загрузка пользователей: отображаются 10 пользователей с именем, email и городом.
2. Поиск по имени: при вводе Leanne отображается подходящий пользователь.
3. Если имя не найдено, выводится сообщение «Пользователи не найдены».
4. При нажатии «Показать публикации» отображаются первые три публикации выбранного пользователя.
5. При замене /users на /userz сервер возвращает HTTP 404 и отображается сообщение об ошибке.
6. После восстановления адреса повторная загрузка доступна.
7. Во время загрузки отображается «Загрузка...».
8. Страница обновляется без перезагрузки.

### Структура проекта
- index.html — структура страницы
- style.css — оформление страницы
- app.js — логика и HTTP-запросы
- README.md — описание работы
